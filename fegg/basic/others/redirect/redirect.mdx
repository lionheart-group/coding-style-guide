# Application::redirect

> Redirect to another URL and stop

## Description

```php
public void Application::redirect( string $url )
```

Send a `Location` header (HTTP 302) and stop the script (`exit`). Code after `redirect()` is not run.

- A URL starting with `http://` or `https://` is used as is.
- Any other URL is a path inside the site. A `/` is added at the start if missing, a trailing `/` is added when the path has no extension (to avoid a second redirect, see [URL](../../url.mdx#trailing-slash)), and the current protocol, domain and base path are added in front. This also works when the site is installed in a subdirectory.

## Arguments

| Name | Data type | Default | Remarks |
| :--- | :-------- | :------ | :------ |
| $url | string    |         | Absolute URL, or a path inside the site |

## Example

```php title="Controller"
// -> https://example.com/news/
$this->redirect('/news/');

// -> https://example.com/news/ (slashes added)
$this->redirect('news');

// -> https://example.com/contact/result.html
$this->redirect('/contact/result.html');

// -> https://www.example.org/
$this->redirect('https://www.example.org/');
```

Do not pass a URL taken from the request (for example `$this->in('return_to')`) without checking it, or the site becomes an open redirect.
