## Ticket

A ticket protects form processing. `setTicket()` creates a random string, stores it in the session and adds it to the form as a hidden field (output with `{{ hidden }}`). When the form is posted, `useTicket()` checks that the posted value matches the session and then removes it, so the same form cannot be processed twice.
