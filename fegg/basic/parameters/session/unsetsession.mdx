# Application::unsetSession

> Unset SESSION data

## Description

```php
public void Application::unsetSession( string $name = '' )
```

Remove one key from the SESSION data. If you omit the argument, `unsetSession` removes all SESSION data and destroys the session.

## Arguments

| Name  | Data type | Default | Remarks                                          |
| :---- | :-------- | :------ | :----------------------------------------------- |
| $name | string    | ''      | Session key. Destroys the whole session when omitted |

## Example

```php title="Controller - First request"
$this->setSession('foo', 'bar');
```

```php title="Controller - Second request"
echo $this->getSession('foo'); // -> bar
```

```php title="Controller - Third request"
$this->unsetSession('foo');
echo $this->getSession('foo'); // -> ''
```

### Remove all session data

If you omit the argument, `unsetSession` removes all SESSION data and destroys the session.

```php title="Controller - First request"
$this->setSession('foo', 'bar');
$this->setSession('baz', 'qux');
```

```php title="Controller - Second request"
$this->unsetSession();
echo $this->getSession('foo'); // -> ''
echo $this->getSession('baz'); // -> ''
```
