# About Parameters

`Fegg\Application`, the class every controller extends, has helper methods for POST, GET, SESSION and COOKIE. Call them with `$this->...` in a controller.

## POST/GET

Get request data. Values are returned as sent: validate them, and let the template escape them on output.

<CategoryDocCardList label="POST/GET" />

## SESSION

Set and read SESSION data. Never call `session_start()` yourself: Fegg starts the session on the first write (`setSession()`, `setTicket()`, the CMS). Reading (`getSession()`, `{{ $session }}`) never starts one, so public pages send no cookie and can be cached.

- The session cookie is `HttpOnly` and `SameSite=Lax`. It is `Secure` when the request is HTTPS (see [HTTPS](../security.mdx#https)).
- `session.use_strict_mode` is on: a session ID the server did not issue is replaced by a new one.
- The session is written when the response ends (see [Ending a response](../controller.mdx#ending-a-response)).
