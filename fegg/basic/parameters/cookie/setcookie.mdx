# Application::setCookie

> Set COOKIE data

## Description

```php
public void Application::setCookie( string $name, string $value, int $expire = '', string $path = '/; SameSite=Strict' )
```

Set COOKIE data. The cookie is always sent with the **`Secure`** and **`HttpOnly`** flags: browsers only send it back over HTTPS (and `localhost`), and JavaScript cannot read it.

## Arguments

| Name    | Data type | Default                | Remarks |
| :------ | :-------- | :--------------------- | :------ |
| $name   | string    |                        | Cookie name |
| $value  | string    |                        | Value |
| $expire | int       | ''                     | Lifetime in **seconds from now**. When omitted (or `0`), 1 week (604800 seconds) |
| $path   | string    | '/; SameSite=Strict'   | Path where the cookie is valid. The default also adds `SameSite=Strict` |

## Example

If you omit the third argument, the cookie expires **after 1 week**.

```php title="Controller"
$this->setCookie('foo', 'bar');
```

Set the lifetime in seconds with the third argument.

```php title="Controller"
// This cookie expires after 60 seconds.
$this->setCookie('foo', 'bar', 60);
```

Set the path with the fourth argument. Append `; SameSite=Strict` (or `Lax`) yourself if you still want the `SameSite` attribute.

```php title="Controller"
// This cookie is only valid under "/test/".
$this->setCookie('foo', 'bar', 0, '/test/; SameSite=Strict');
```
