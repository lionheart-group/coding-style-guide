# Variable

> Output variables

## Description

```html
{{ $var }}
{{ $var.key.sub }}
{{ $var|modifier }}
```

`{{ $var }}` outputs a variable. Array elements are separated with a period: `$var.key.sub` is `$var['key']['sub']`. Numeric keys and keys that are PHP keywords work too (`$rows.0.name`, `$item.new`, `$site.default`). Square brackets take an expression as the key: `$page.data[$id]`, `$map[$key].name`.

Values from the controller are set in `$this->page` and read as `$page` in the template. The other variables available in a page are listed in [Application::fetchPage](../methods/fetchpage.mdx#template-variables).

The output is escaped with `htmlspecialchars` (`ENT_QUOTES`), which is right for HTML text and quoted attribute values. Other places (URLs, JavaScript) need a modifier: see [Security](../security.mdx). To output trusted HTML as it is, use the `noescape` modifier (see [Modifiers](../modifiers.mdx)).

Nothing is output (and no error is raised) when the variable is not set or is an array. This check is made on the variable itself, before any modifier runs.

Inside a tag, `$a.b` is always array access. To concatenate strings in an expression (`if`, `assign` …), write the PHP operator with spaces: `$a . $b`.

## Example

```php title="Controller"
$this->page['title'] = 'Hello';
$this->page['rows'] = array(
    array('name' => 'first'),
);
$this->displayPage('template');
```

```html title="Template"
{{ $page.title }}
{{ $page.rows.0.name }}
{{ $page.missing }}
```

```html title="Output"
Hello
first

```

### Escaping and `noescape`

```php title="Controller"
$this->page['foo'] = '<p>bar</p>';
```

```html title="Template"
{{ $page.foo }}
{{ $page.foo|noescape }}
```

```html title="Output"
&lt;p&gt;bar&lt;/p&gt;
<p>bar</p>
```

:::warning

Use `noescape` only for HTML you trust (CMS rich text written by administrators, messages from your own config). Never use it on request parameters (`$in`) or other user input.

:::
