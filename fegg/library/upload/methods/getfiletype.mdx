# Upload::getFileType

> Get the allowed file types (extensions)

## Description

```php
public array Upload::getFileType()
```

## Example

```php title="Controller"
use Fegg\Tool\Upload;

$upload = new Upload();
var_dump($upload->getFileType()); // -> array('jpg', 'jpeg', 'png', 'gif')
```
