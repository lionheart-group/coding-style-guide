# Upload::setUploadDir

> Set the upload directory

## Description

```php
public boolean Upload::setUploadDir( string $dir )
```

The directory is created (recursively) when it does not exist. Returns `true` when the directory is writable, otherwise `false` and the directory is not set.

## Arguments

| Name | Data type | Default | Remarks          |
| ---- | --------- | ------- | ---------------- |
| $dir | string    |         | Upload directory |

## Example

```php title="Controller"
use Fegg\Tool\Upload;

$upload = new Upload();
$upload->setUploadDir($this->config['upload_dir']['path']);
```
