# Model::setTableName

> Set Table Name

## Description

```php
public self Model::setTableName( string $table )
```

Throws `InvalidArgumentException` when `$table` is not a plain name (letters, digits and `_`).

## Arguments

| Name   | Data type | Default | Remarks           |
| ------ | --------- | ------- | ----------------- |
| $table | string    |         | Target table name |

## Example

```php title="Controller"
$model = new Model();
$model->setTableName('cms_news');

// Same as the following
$model = new Model(false, array(
    'table' => 'cms_news',
));
```
