# Model::delete

> Execute Logical Delete the record by specified primary ID

## Description

```php
public int Model::delete( mixed $id )
```

Soft-deletes the row whose primary key is `$id`: sets `valid = 0` (and `modified`), so reads no longer return it. Returns the number of updated rows. To remove the row from the table, use [erase](./erase.mdx).

## Arguments

| Name | Data type | Default | Remarks                    |
| ---- | --------- | ------- | -------------------------- |
| $id  | mixed     |         | Deleting target Primary ID |

## Example

```php title="Controller"
$model = new Model(true, array(
    'table'   => 'cms_news',
    'id'      => 'news_id',
    'visible' => 'visible',
));

$deleted = $model->delete(1);
// -> 1
```
