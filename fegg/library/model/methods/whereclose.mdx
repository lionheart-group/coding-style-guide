# Model::whereClose

> Add close bracket on Where query

## Description

```php
public self Model::whereClose()
```

Closes the bracket opened with [whereOpen](./whereopen.mdx).

## Example

```php title="Controller"
$model = new Model(false, array(
    'table'   => 'cms_news',
    'id'      => 'news_id',
    'visible' => 'visible',
));

$model->where('category = ?', 2);
$model->whereOpen();
$model->where('title = ?', 'foo');
$model->where('post_date <= ?', '2021-01-01', 'OR');
$model->whereClose();

// Select *
// From "cms_news"
// Where category = 2
//   AND (title = 'foo' OR post_date <= '2021-01-01')
//   AND cms_news.visible = '1' And "cms_news".valid = 1
$records = $model->find();
```
