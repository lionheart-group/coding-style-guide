# Model::dropTable

> Execute Drop table

## Description

```php
public void Model::dropTable()
```

Drops the model's table. Throws `Fegg\Database\QueryException` when the query fails.

## Example

```php title="Controller"
$model = new Model(true, array(
    'table' => 'sample',
));

// Drop Table "sample"
$model->dropTable();
```
