# Embed::isYoutubeShort

> Check whether a URL is a YouTube short

## Description

```php
public static bool Embed::isYoutubeShort( string $url )
```

Returns `true` when `$url` is a YouTube short (`/shorts/<id>`). [Embed::youtube](./youtube.mdx) shows a short 9:16 unless another ratio is given.

## Arguments

| Name | Data type | Default | Remarks     |
| ---- | --------- | ------- | ----------- |
| $url | string    |         | YouTube URL |

## Example

```php title="Controller"
use Fegg\Embed;

Embed::isYoutubeShort('https://www.youtube.com/shorts/dQw4w9WgXcQ');  // -> true
Embed::isYoutubeShort('https://www.youtube.com/watch?v=dQw4w9WgXcQ'); // -> false
```
