# Mail::log

> Append a message to the log file

## Description

```php
public boolean Mail::log( string $message )
```

Appends a separator line and `$message` to the log file ([Mail::logFile](./logfile.mdx): the file given to [Mail::setDebugFlag](./setdebugflag.mdx), by default `mail.log` in the log directory). Nothing is written when the file or its directory is not writable. The return value is always `true`.

[Mail::send](./send.mdx) calls this method with the whole message when the debug flag is enabled.

## Arguments

| Name     | Data type | Default | Remarks     |
| -------- | --------- | ------- | ----------- |
| $message | string    |         | Log message |

## Example

```php title="Controller"
use Fegg\Tool\Mail;

$mail = new Mail();
$mail->setDebugFlag(true);
$mail->log('Contact form posted');
```
