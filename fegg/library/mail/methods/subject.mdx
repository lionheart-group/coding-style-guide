# Mail::subject

> Set mail subject

## Description

```php
public self Mail::subject( string $subject )
```

## Arguments

| Name     | Data type | Default | Remarks       |
| -------- | --------- | ------- | ------------- |
| $subject | string    |         | Email subject |

## Example

```php title="Controller"
use Fegg\Tool\Mail;

$mail = new Mail();
$mail->subject('Mail subject');
```
