# Trim::create

> Save the image to the output path

## Description

```php
public void Trim::create()
```

Saves the resized image to the output path given to [Trim::setImage](./setimage.mdx). Missing directories are created. JPEG images are saved with quality 90.

## Example

```php title="Controller"
use Fegg\Tool\Trim;

$trim = new Trim();
$trim->setImage('path/to/image.jpg', 'path/to/converted.jpg');

$trim->resizeTrim(300, 300, 'm');
$trim->create();
```
