# About Extension libraries

Fegg's goal is lightweight and less typing, so the controller base class only has the minimum required functions. Additional functions are provided as library classes in the core (`htdocs/_fegg/core/src/`).

## How to use

Every library is a namespaced class that is loaded by the autoloader. Import it with `use` and create it with `new`.

```php title="Controller"
<?php
namespace Site\Controller;

defined('FEGG_CORE_DIR') || exit;

use Fegg\Tool\Mail;
use Fegg\Tool\Validation;

class Contact extends Controller
{
    public function post()
    {
        $validation = new Validation();
        $validation->required('mail', $this->in('mail'), array('@required', 'Email'));

        if (!$validation->isError()) {
            $mail = new Mail('Mail subject', 'Mail body');
            $mail->send($this->in('mail'), 'Sender name', 'from@example.com');
        }
    }
}
```

## Extension Libraries

The libraries are in the `Fegg\Tool\` namespace. `Fegg\Model`, `Fegg\Database\Pdo`, `Fegg\Http\Client` and `Fegg\Log` are framework classes, not in `Fegg\Tool\`.

| Library | Class | Description |
| --- | --- | --- |
| [Validation](./validation/index.mdx) | `Fegg\Tool\Validation` | Form validation |
| [Database](./database/index.mdx) | `Fegg\Database\Pdo` | Database access (PDO) |
| [Model](./model/index.mdx) | `Fegg\Model` | Models: queries and rows |
| [File](./file/index.mdx) | `Fegg\Tool\File` | File and directory operations |
| [Upload](./upload/index.mdx) | `Fegg\Tool\Upload` | Uploads and file checks |
| [Mail](./mail/index.mdx) | `Fegg\Tool\Mail` | Sending mail (PHPMailer) |
| [RSS](./rss/index.mdx) | `Fegg\Tool\RSS` | Reading RSS / Atom feeds |
| [Trim](./trim/index.mdx) | `Fegg\Tool\Trim` | Resizing and cropping images |
| [Embed](./embed/index.mdx) | `Fegg\Tool\Embed` | Embedding YouTube videos and Google Maps the way the editor does |
| [Captcha](./captcha/index.mdx) | `Fegg\Tool\Captcha\ReCAPTCHA`, `Fegg\Tool\Captcha\Turnstile` | Verifying Google reCAPTCHA / Cloudflare Turnstile responses |
| [Yaml](./yaml/index.mdx) | `Fegg\Tool\Yaml` | Reading and writing YAML files |
| [HTTP client](./http-client/index.mdx) | `Fegg\Http\Client` | Requests to other services over HTTP |
| [Log](./log/index.mdx) | `Fegg\Log` | Writing to the application log |

| [JSON-LD](./json-ld/index.mdx) | `Fegg\Tool\JsonLd` | Structured data for search engines |
| [Feed](./feed/index.mdx) | `Fegg\Tool\Feed` | Writing an RSS 2.0 feed of the site's posts |

## Project libraries

Put your own classes in `htdocs/_fegg/site/src/` with the `Site\` namespace. They are autoloaded in the same way.

```php title="htdocs/_fegg/site/src/MyLib/Foo.php"
<?php
namespace Site\MyLib;

defined('FEGG_CORE_DIR') || exit;

class Foo
{
}
```

```php title="Controller"
use Site\MyLib\Foo;

$foo = new Foo();
```

## External Libraries

These libraries are bundled in `htdocs/_fegg/core/vendor/` and autoloaded.

- [PHPMailer](https://github.com/PHPMailer/PHPMailer) (7.2)
  - Used by [Mail](./mail/index.mdx). Namespace `PHPMailer\PHPMailer`
  - A failed send throws `PHPMailer\PHPMailer\Exception`

JSON documents are handled with PHP's own `json_encode` and `json_decode`, YAML with [Yaml](./yaml/index.mdx).
