# Pdo::unsetRegularUseQueryForTable

> Disable automatic append query of the table for a current query flag

## Description

```php
public self Pdo::unsetRegularUseQueryForTable()
```

For the next query only, skips the queries configured for the table (the `table` section of `database_regular_use_query.php`, see [Configuration](../configuration.mdx)). The queries added for every table still apply.

## Example

```php title="Controller"
$db = new \Fegg\Database\Pdo();

$rows = $db->unsetRegularUseQueryForTable()->select('cms_news')->execute()->all();
```
