# Pdo::getReturnCode

> Get return code of the last executed query

## Description

```php
public int|null Pdo::getReturnCode()
```

Returns the number of affected rows of the last query that was not a SELECT or PRAGMA (`null` before the first one). Prefer [getAffectedRow](./getaffectedrow.mdx). A failed query throws `Fegg\Database\QueryException`, so there is no error code to check.

## Example

```php title="Controller"
$db = new \Fegg\Database\Pdo();

$db->setValues(array('title' => 'Sample'))->insert('cms_news')->execute();
$code = $db->getReturnCode();
// -> 1
```
