# Pdo::disabledRegularUseQuery

> Disable automatic append query flag

## Description

```php
public self Pdo::disabledRegularUseQuery()
```

Skips every automatic query (for every table and for the table, see [Configuration](../configuration.mdx)) for every later query of this instance. To skip them for one query only, use [unsetRegularUseQuery](./unsetregularusequery.mdx) and [unsetRegularUseQueryForTable](./unsetregularusequeryfortable.mdx).

## Example

```php title="Controller"
$db = new \Fegg\Database\Pdo();
$db->disabledRegularUseQuery();

// Select * From "cms_news"  (also the rows with valid = 0)
$rows = $db->select('cms_news')->execute()->all();
```
