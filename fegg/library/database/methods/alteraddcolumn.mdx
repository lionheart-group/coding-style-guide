# Pdo::alterAddColumn

> Set create alter add column query

## Description

```php
public self Pdo::alterAddColumn( string $table, array $field )
```

Builds `Alter Table "table" ADD COLUMN ...`.

## Arguments

| Name   | Data type | Default | Remarks                                                                  |
| ------ | --------- | ------- | ------------------------------------------------------------------------ |
| $table | string    |         | Table name                                                               |
| $field | array     |         | Column definition, with every key described in [createTable](./createtable.mdx) |

## Example

```php title="Controller"
$db = new \Fegg\Database\Pdo();

// Alter Table "sample" ADD COLUMN note TEXT
$db->alterAddColumn('sample', array(
    'name'       => 'note',
    'type'       => 'TEXT',
    'notnull'    => false,
    'dflt_value' => null,
    'pk'         => false,
    'ai'         => false,
))->execute();
```
