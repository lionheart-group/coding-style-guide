# File::createDirectory

> Create a directory

## Description

```php
public bool File::createDirectory( string $directory, [ string|int $permission = '0755' ] )
```

Creates `$directory` and its missing parent directories with the permission `$permission`. Returns `true` when the directory exists afterwards (also when it existed already), `false` when it could not be created.

## Arguments

| Name        | Data type  | Default | Remarks                          |
| ----------- | ---------- | ------- | -------------------------------- |
| $directory  | string     |         | Directory to create              |
| $permission | string/int | '0755'  | Permission, `'0755'` or `0755`   |

## Example

```php title="Controller"
use Fegg\Tool\File;

$file = new File();
$file->createDirectory('path/to/new_directory');
```
