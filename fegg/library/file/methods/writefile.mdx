# File::writeFile

> Write data to a file

## Description

```php
public bool File::writeFile( string $file, string $data, [ string $writeOption = 'a' ] )
```

Opens `$file` with the `fopen()` mode `$writeOption`, writes `$data` and sets the permission of the file to `0644` (readable by everyone). The default mode `a` appends to the file; use `w` to overwrite it.

Returns `false` when the file cannot be opened or written.

## Arguments

| Name         | Data type | Default | Remarks                                    |
| ------------ | --------- | ------- | ------------------------------------------ |
| $file        | string    |         | File to write                              |
| $data        | string    |         | Data to write                              |
| $writeOption | string    | 'a'     | `fopen()` mode (`a`: append, `w`: overwrite) |

## Example

```php title="Controller"
use Fegg\Tool\File;

$file = new File();

// Append a line
$file->writeFile('path/to/foo.log', date('Y-m-d H:i:s') . " done\n");

// Overwrite the file
if (!$file->writeFile('path/to/foo.txt', 'New contents', 'w')) {
    // could not be written
}
```
