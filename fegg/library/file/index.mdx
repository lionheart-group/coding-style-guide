# Introduction

> Providing some functions for managing files/directories

## How to use

Import `Fegg\Tool\File` and create it with `new`.

```php title="Controller"
<?php
namespace Site\Controller;

defined('FEGG_CORE_DIR') || exit;

use Fegg\Tool\File;

class Export extends Controller
{
    public function index()
    {
        $file = new File();

        if (!$file->createDirectory(FEGG_SITE_DIR . '/data/export')
            || !$file->writeFile(FEGG_SITE_DIR . '/data/export/list.csv', "id,title\n", 'w')) {
            throw new \RuntimeException('The export could not be written');
        }
    }
}
```

:::note

Every method returns `true` when it did its work and `false` when something could not be done (a missing source, a file that cannot be written, a directory that cannot be read ...). [File::readFile](./methods/readfile.mdx) returns the content instead, `''` when the file cannot be read.

Symbolic links are never followed when a directory is removed, copied or touched: a link is removed (or skipped), never what it points to.

:::
