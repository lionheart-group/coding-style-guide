# Date::addDay

> Add days to a date

## Description

```php
public string Date::addDay( string $dateTime, int $interval, [ string $format = 'Y-m-d H:i:s' ] )
```

Returns `$dateTime` plus `$interval` days, formatted with `date()` format `$format`. Use a negative `$interval` to subtract days.

## Arguments

| Name      | Data type | Default       | Remarks                                  |
| --------- | --------- | ------------- | ---------------------------------------- |
| $dateTime | string    |               | Base date and time                       |
| $interval | int       |               | Number of days (negative: before)        |
| $format   | string    | 'Y-m-d H:i:s' | `date()` format of the result            |

## Example

```php title="Controller"
use Fegg\Tool\Date;

$date = new Date();

echo $date->addDay('2024-04-01 10:00:00', 7);         // -> "2024-04-08 10:00:00"
echo $date->addDay('2024/04/01', -1, 'Y/m/d');        // -> "2024/03/31"
```
