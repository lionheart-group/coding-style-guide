# Validation::password

> Check password format

## Description

```php
public boolean Validation::password( string $name, mixed $value, [ mixed $code = '', boolean $mixedLettersFlag = false ] )
```

Valid when the value contains only `0-9`, `a-z`, `A-Z` and `-_@!#`. With `$mixedLettersFlag` it must also contain at least one letter and one digit; use the error code `@password_mixed_letters` for that message. The length is not checked: combine with [Validation::minlength](./minlength.mdx).

An empty value (`''`, `null`, `'0'`, whitespace only) is not checked and returns `true`: combine with [Validation::required](./required.mdx) when the field is required. When `$name` already has an error, the check is skipped and returns `false`, so only the first error of each field is kept.

## Arguments

| Name              | Data type | Default | Remarks                                                                                                      |
| ----------------- | --------- | ------- | ------------------------------------------------------------------------------------------------------------ |
| $name             | string    |         | Field name (key of the error message)                                                                        |
| $value            | mixed     |         | Value to check                                                                                               |
| $code             | mixed     | ''      | Error code, array of error code and parameters, or error message (see [Configuration](../configuration.mdx)) |
| $mixedLettersFlag | boolean   | false   | `true`: require both letters and digits                                                                      |

## Example

```php title="Controller"
use Fegg\Tool\Validation;

$validation = new Validation();

$validation->password('success', 'secret_123', array('@password', 'Password')); // -> true
$validation->password('failed', 'pass word', array('@password', 'Password')); // -> false

var_dump($validation->getErrorMessage());
// -> array('failed' => '<strong>Password</strong> は登録できない形式です')

// Letters and digits are both required
$validation->password('password2', 'secret', array('@password_mixed_letters', 'Password'), true); // -> false
```
