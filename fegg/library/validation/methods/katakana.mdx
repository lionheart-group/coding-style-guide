# Validation::katakana

> Check Katakana characters for Japanese language

## Description

```php
public boolean Validation::katakana( string $name, mixed $value, [ mixed $code = '', boolean $zenkakuFlag = false ] )
```

By default the value must contain only **half-width** Katakana and half-width symbols (`｡` to `ﾟ`), spaces, `(`, `)` and `.`. With `$zenkakuFlag` it must contain only **full-width** Katakana (`ァ`-`ヶ`), `ー` and full-width spaces.

An empty value (`''`, `null`, `'0'`, whitespace only) is not checked and returns `true`: combine with [Validation::required](./required.mdx) when the field is required. When `$name` already has an error, the check is skipped and returns `false`, so only the first error of each field is kept.

## Arguments

| Name         | Data type | Default | Remarks                                                                                                      |
| ------------ | --------- | ------- | ------------------------------------------------------------------------------------------------------------ |
| $name        | string    |         | Field name (key of the error message)                                                                        |
| $value       | mixed     |         | Value to check                                                                                               |
| $code        | mixed     | ''      | Error code, array of error code and parameters, or error message (see [Configuration](../configuration.mdx)) |
| $zenkakuFlag | boolean   | false   | `true`: full-width Katakana only / `false`: half-width Katakana only                                         |

## Example

```php title="Controller"
use Fegg\Tool\Validation;

$validation = new Validation();

$validation->katakana('success', 'ﾃｽﾄ', array('@katakana', 'Kana')); // -> true
$validation->katakana('failed', 'テスト', array('@katakana', 'Kana')); // -> false

var_dump($validation->getErrorMessage());
// -> array('failed' => '<strong>Kana</strong> はカタカナで入力してください')

// Full-width Katakana
$validation->katakana('furi', 'テスト', array('@katakana', 'Furigana'), true); // -> true
```
